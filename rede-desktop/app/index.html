Entrar

Sem login, sem senha. Só escolha um nome para aparecer no chat e nas chamadas — quantas pessoas quiserem podem entrar.

Configure o firebase-config.js com os dados do seu projeto Firebase antes de usar (veja o README).

Criar servidor

Um servidor é um espaço separado, com seus próprios canais, chat e chamadas. Coloque uma senha se quiser que só quem souber dela consiga entrar.
